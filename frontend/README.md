# Krusty Krab Ops Board (frontend)

Vite + React + TypeScript dashboard for the Campus Customs agent team. Install once with `npm install`, then start it with `npm run dev` and open http://localhost:5181. It talks to the FastAPI backend on http://localhost:8000.

See the project `README.md` for the full run order, and `output/design.md` for the design.
